# Perbaikan invoice dan alur input

- Cetak / Simpan PDF memakai dokumen invoice tersendiri, menunggu stylesheet dan gambar selesai dimuat.
- Chat WA membuka nomor terbaru pada kontak pelanggan. Kirim invoice menyiapkan pesan berisi item, jumlah, total, status, dan tautan PDF jika tersedia. Pengguna menekan Kirim di WhatsApp; aplikasi tidak menggunakan WhatsApp Business API.
- Edit kontak, produk, biaya, dan akun menunggu penyimpanan server sebelum memperbarui data lokal. Jika gagal, formulir tetap tersedia untuk dicoba ulang.
- Owner dapat mengedit transaksi: tanggal, pelanggan, produk, jumlah, harga, diskon, catatan, metode dan status pembayaran. Stok disesuaikan berdasarkan selisih jumlah lama dan baru. Transaksi return tidak dapat diedit.
- Transaksi baru dapat dipilih Lunas atau Belum lunas untuk semua metode pembayaran.
- Halaman Kategori, Item Produk, dan Input HPP terpisah. Formulir produk di samping daftar pada desktop, dengan daftar bergulir sendiri. Pada HP tersedia tab Input Produk dan Daftar & Edit. Posisi halaman dan isian formulir dipertahankan saat data dirender ulang.

## Aktivasi

1. Perbarui proyek Google Apps Script perusahaan dengan `gas/Code.gs`, lalu deploy versi baru pada deployment web app yang sama (pertahankan URL `/exec`). Endpoint baru `editTransaction` diperlukan. Data Center tidak perlu diubah.
2. Merge perubahan frontend dan deploy ke Vercel. Versi aset dan cache PWA telah dinaikkan.
3. Uji di akun owner: cetak invoice, buka Chat WA, kirim invoice (tanpa benar-benar mengirim ke pelanggan uji), edit kontak/produk/biaya, ubah email/password akun uji lalu login ulang, dan edit jumlah/status transaksi. Pastikan stok dan PDF terbaru sesuai.

## Validasi yang sudah dijalankan

`node tools/validate.js`, `node tools/decimal-quantity.test.cjs`, `node tools/invoice-crud.test.cjs`.

Uji mencakup nomor WA, rincian pesan, kegagalan layanan PDF, CRUD dan kegagalan simpan server, pemisahan formulir kategori/produk, jumlah desimal, total transaksi, selisih stok, pengulangan permintaan, batas tenant, dan larangan edit transaksi return.

Preview Vercel berhasil diuji dengan akun demo: edit harga produk tersimpan, edit jumlah/status transaksi mengubah total dan stok, dan tombol cetak membuka dokumen invoice untuk dialog cetak. Uji regresi juga mencakup input tersembunyi bernama id yang sebelumnya menghalangi dispatch formulir edit. Login ulang setelah perubahan akun, PDF Google Drive, dan integrasi Google Apps Script aktif masih memerlukan verifikasi pada deployment perusahaan.
